# Четыре в ряд: ИИ, который научился сам

Нейросеть для игры «4 в ряд» (поле 7×6), обученная в стиле AlphaZero:
она играет сама с собой, а поиск по дереву (MCTS) подсказывает ей, какие ходы были лучше.
Никаких готовых партий или правил стратегии ей не давали: только правила игры.

## Как сыграть

**В браузере.** Откройте `web/index.html` (рядом должен лежать `web/weights.js` с весами сети).
Можно выбрать, кто ходит первым, и силу ИИ:

| Уровень   | Что делает ИИ |
|-----------|---------------|
| Новичок   | ходит по «первому впечатлению» сети, без расчёта |
| Средний   | 60 симуляций MCTS на ход |
| Сильный   | 400 симуляций |
| Максимум  | 2000 симуляций |

Под доской видно, какие столбцы ИИ рассматривал, а справа показано, как он оценивает позицию.

**В терминале.**

```bash
pip install -r requirements.txt
python play.py              # вы ходите первым
python play.py --second     # первым ходит ИИ
python play.py --sims 2000  # сильнее, но дольше думает
```

## Как это устроено

- `connect4/game.py`: правила на битбордах (быстрая проверка четырёх в ряд).
- `connect4/net.py`: нейросеть на чистом NumPy (без PyTorch): 84 входа (свои и чужие фишки),
  три скрытых слоя 384–384–256 и две «головы». Голова политики выдаёт вероятности ходов,
  голова ценности оценивает позицию от −1 до +1. Обратное распространение и Adam написаны вручную.
- `connect4/mcts.py`: поиск PUCT, как в AlphaZero. Сеть подсказывает, какие ходы смотреть,
  и оценивает позиции вместо доигрывания до конца.
- `connect4/selfplay.py`: пакетная самоигра. Сотни партий идут одновременно,
  чтобы сеть оценивала позиции большими пачками.
- `train.py`: цикл обучения: самоигра на всех ядрах → обучение на последних ~400 тыс. позиций → повтор.
  Цели обучения: распределение посещений MCTS для политики и среднее между итогом партии
  и оценкой поиска для ценности. Каждая позиция добавляется ещё и в зеркальном виде.
- `evaluate.py`: проверка силы против случайного игрока и классического альфа-бета перебора
  на 2, 4 и 6 полуходов.
- `web/index.html`: игра в браузере. Сеть и MCTS переписаны на JavaScript,
  веса берутся из `web/weights.js`.

## Обучить заново или продолжить

```bash
python train.py --minutes 60             # с нуля
python train.py --minutes 60 --resume    # продолжить с models/latest.npz
python evaluate.py --sims 200 --games 40 # измерить силу
```

После каждого цикла обучения `train.py` сохраняет `models/latest.npz` и обновляет `web/weights.js`,
а журнал пишет в `models/train_log.jsonl`.
